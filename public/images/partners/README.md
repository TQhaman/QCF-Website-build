## Display notes

- Cortex Hub supplies a white transparent mark. Give it a dark backing, without
  recolouring its pixels. The original contains generous transparent padding.
- Eastern Cape's standalone departmental logo is 263 × 66 pixels. Keep its
  display width at or below the source width and include the readable partner
  name alongside/below it; a higher-resolution approved file would be useful.
- Coca-Cola uses the consumer-brand script, not The Coca-Cola Company or a
  bottling-company mark.
- FFG uses the current high-resolution logo displayed by its official website,
  rather than the older low-resolution header on the legacy about page.
